# Institute content

The digest-verified fork artifact is the source of truth for lesson JSON and audio. `artifact.ts` owns the six-chapter Ratstack order and the artifact pin. Vite validates the input before copying only the selected chapter manifests, hashed section JSON, referenced WebM and optional AAC, and the home OG into Website static assets. The course manifest is derived from that selection. Kit's chapters are not copied. Nothing loads the fork's React bundle, includes lesson bytes in Worker JavaScript, or adds a storage service.

For a local proof, set `INSTITUTE_CONTENT_ARTIFACT` to the output of the desk's `institute-artifact.sh path <sha>` using the full SHA in `artifact.ts`. Run `pnpm --filter @rat-stack/web exec vitest run test/institute-content.test.ts` to check the pinned corpus; leave the variable unset for ordinary CI. To rotate the artifact, update the SHA and digest together and rerun the corpus check and Website build. The artifact build is not byte-reproducible, so the commit SHA alone is not a pin.

Keep `INSTITUTE_CONTENT_ARTIFACT` unset on deployed builds until the `/institute` Worker-first routing gate lands. This variable is separate from the legacy `INSTITUTE_ARTIFACT` that provisions the fork Worker. The serving dispatcher forwards Range to the native `ASSETS` binding and preserves 206 and `Content-Range`. If `ASSETS` answers with a full 200, the dispatcher handles a single range on the bounded, hashed media only. Apply immutable cache headers to successful hashed JSON, WebM and AAC responses, never to manifests or 404s. On an enabled preview, fetch a `webm` with `Range: bytes=0-31` and check for 206, the matching `Content-Range`, and a 32-byte body. On a disabled preview, the same URL must return the site's normal 404, even when the asset exists.

The current pin stages 71 files: 7,573,963 WebM bytes (largest file 518,262 bytes), 5,850,402 AAC bytes (largest file 390,738 bytes), 568,143 JSON bytes including the generated index, and a 50,675-byte OG PNG. Total: 14,043,183 bytes. No lesson bytes count toward Worker startup. The `InstituteContent` service reads through a caller-supplied asset adapter and returns `audioUrl(...) === undefined` when the section has no primary narration. When `audioFallbackFile` is set, `audioFallbackUrl(...)` derives the optional hashed AAC URL for playback as `audio/mp4`.
