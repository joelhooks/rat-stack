# Qualify CI and stage

Use the project mapping for required checks, runner admission and stage ownership. Preserve the required check name on every skip path.

Bind proof to the exact merged candidate, run attempt, deployed versions and configuration. A queued or cancelled run is not a passing run.

Require synthetic end-to-end behavior through isolated providers. Qualification ends on reconciled event coverage, not elapsed time. Do not borrow another stage or production credentials.
