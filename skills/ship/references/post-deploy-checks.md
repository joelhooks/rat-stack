# Verify the deployed release

Use complete, candidate-bound, secret-free inputs. Preserve read failures as HOLD. Do not mistake an advisory verdict for a completed required read.

Use the owning evaluators and collector contracts. A file evaluator is not a live collector or permission to promote.

Check versions, actor recovery and receipts. Read customer-facing links, prices, pages and email outcomes signed out.

Read the project mapping for commands and required evidence. The release machine owns promotion and restoration decisions.
