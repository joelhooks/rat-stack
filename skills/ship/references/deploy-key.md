# Install or rotate a deploy key

Read the project's credential procedure before acting. Installing a key and proving its authority are separate steps.

Use the narrowest approved resource scope. Verify the actual deployment, state and preview operations without printing credentials.

Rotation needs its own authorization. Prove the replacement binding before revoking the old key. Respect the runner's expiry refusal.

A token verification response or successful scope probe does not prove that deployment works.
