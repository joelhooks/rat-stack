# Look up discoverable facts before asking

**Applies when:** entering unfamiliar code or deciding whether to ask.

Read repo law, owning source, tests, and matching pinned library sources. Ask only for missing decisions that observation cannot settle.

**Why:** An answer from stale examples can be worse than no answer.

**Example:** `skills/gardener/SKILL.md` checks manifests and matching source mirrors before studying changed APIs.
