# Use plain language for one claim at a time

**Applies when:** writing docs, skills, or system pages.

Use active verbs, consistent terms, and short sentences. Link evidence and preserve quoted voice instead of adding unsupported claims.

**Why:** Readers need the claim and next action, not ornamental prose.

**Example:** `skills/write-a-wiki-page/SKILL.md` replaces passive decoding prose with a direct handler action.

**Held by:** `write-a-wiki-page`, steps 2 and 5; `apps/mischief/test/wiki-prose.test.ts` tests warning behavior, not style compliance.
