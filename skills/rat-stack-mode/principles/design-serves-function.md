# Make visual design serve function

**Applies when:** changing layout, focus, or visual emphasis.

Use emphasis to show the next useful distinction. Keep focus visible and use the accent only where repo law permits it.

**Why:** Competing emphasis and broken layouts make the intended action harder to find.

**Example:** `apps/mischief/test/accent.test.ts` restricts pink selectors; responsive table tests check cell labels and focusable regions.

**Held by:** `apps/mischief/test/accent.test.ts`; `apps/mischief/test/responsive-tables.test.ts`; review for visual usability.
