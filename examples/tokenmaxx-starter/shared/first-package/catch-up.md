# 01.1 catch-up

`catch-up.tgz` holds a first package someone already started. Rename everything.

`pnpm ex 01.1 catch-up` unpacks it into `.pi/catch-up/01.1/`, which git ignores, and switches on its entry in `.pi/settings.json`. Every fresh Pi in this repo loads it after that. Its own README explains the rest.
